# AI for Alzheimer's Drug Discovery — 8-Week Learning Plan

**Цель:** за 8 недель дойти до воспроизводимого ML-проекта — модели, предсказывающей проникновение малых молекул через гематоэнцефалический барьер (BBBP).

**Формат работы:** 8–12 часов в неделю. Отмечайте выполненные шаги в чекбоксах и коммитьте изменения в GitHub.

---

## Как пользоваться планом

1. Создайте новый GitHub-репозиторий, например `alzheimers-ai-roadmap`.
2. Скопируйте этот файл в корень репозитория как `ROADMAP.md`.
3. Создайте папки:
   - `notebooks/`
   - `data/`
   - `models/`
   - `reports/`
4. После завершения шага меняйте `- [ ]` на `- [x]`.
5. В конце каждой недели делайте коммит с кратким итогом.

Пример коммита:

```bash
git add ROADMAP.md notebooks/
git commit -m "Week 1: completed Python and ML basics"
git push
```
